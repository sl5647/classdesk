教学文件管理 · 使用说明
======================

一、怎么打开
------------
双击桌面上的「教学文件管理」图标（或 D:\课程文件库\教学文件管理.exe）。
等 2～3 秒，弹出软件自己的窗口（不是浏览器，没有地址栏和标签页）。

· 关闭窗口 = 退出软件（后台服务同时关掉，不残留）
· 最小化到任务栏不会退出
· 再双击桌面图标：如果已经在运行，会把窗口重新调到前面，不会重复开

二、东西放在哪
--------------
程序：  D:\课程文件库\（目录名以后可以改，改完快捷方式要重建）
  教学文件管理.exe        程序本体（双击它）
  runtime\node.exe      自带的运行引擎，不用你装 Node
  server.js / lib\      程序逻辑
  public\               界面文件
  ui-data\              界面缓存（可删，会自动重建）
  config.json           端口、库目录、源文件夹
  launcher.cs           外壳源码（要改程序才用得到）

资料库：D:\大华教育库\        （已导入 1700 多个文件，约 2 GB）
原件：  D:\C盘归档\桌面资料\大华教育\   ← 一个字没动，确认没问题后可以自己删

资料库内部：
  .lib\index.json  搜索索引（删了会自动重建）
  .lib\meta.json   标签和备注
  .lib\backup\     在线编辑前的自动备份
  .lib\trash\      回收站

三、怎么找文件
--------------
· 顶上搜索框：文件名 + 正文一起搜。Word、Excel、PPT、txt、py、sb3 都能搜正文。
· 多个关键词用空格隔开，意思是"都要有"。例： 斗门 考勤
· 左栏再缩小范围：类型、标签、文件夹、大小、日期。
· 点列头排序；右边详情看正文预览和命中位置。

四、怎么改
----------
改名 · 移动 · 删除 · 打标签 · 写备注 —— 选中文件，右边点按钮。
批量：勾选多个，上面一排按钮（打标签 / 移动 / 删除）一次处理。
删除进回收站，能恢复；确认没用了再去回收站「彻底删除」。

改内容（不用离开软件）：
· 右边面板只负责「预览」，不再放编辑框。要改就点按钮，会弹出一个大窗口。
· Word（.docx）：点「编辑正文」→ 大窗口里按原文档的格式显示（标题居中加粗、字号、对齐、表格边框都一样），
  直接点文字就能改，改完点「保存」。图片、页眉、页脚这里不动。
· Excel（.xlsx）：点「编辑表格」→ 大窗口里是带格式的表格（列宽、行高、合并单元格、底色、加粗都照原样），
  双击单元格改字，回车确认，底部会显示改了几个格子，再点「保存」。公式单元格灰色，不能改。
· 文本（.txt / .py / .csv）：点「编辑文本」→ 大窗口里是整屏编辑区。
· 大窗口按 Esc 或点「取消」就能退出，不会改动原文件。
保存前自动备份到 .lib\backup。改的是资料库副本，原件不动。

五、往库里加文件
----------------
· 把文件/文件夹直接拖进软件窗口 → 自动复制进资料库。
· 或点右上「＋ 导入文件」→ 来源文件夹那一行点「选择文件夹…」，
  软件里会打开一个文件夹选择窗口：左边点盘符/桌面/下载，右边列出文件夹，
  双击进去，单击选中，再点「选这个文件夹」就填好了，不用手打路径。
  选好后点「开始导入」。
· 路径框也还能手动改/粘贴，习惯打字的照旧。
· 同名文件自动改成 "名字(2)"，不覆盖。
· 手动往 D:\大华教育库 拷了文件，点「重建索引」。

六、设置
--------
右上齿轮：库目录、源文件夹、端口、退出程序。
端口默认 7788。被占用就换个数字（如 7790），保存后重开软件。

七、注意
--------
· 不用装 Node.js —— 引擎就在 runtime 文件夹里。
· 界面用的是 Windows 自带的 Edge 内核（WebView2 运行时，Win10/11 一般都有）。
  万一窗口白屏，说明 WebView2 运行时被删了，装一下「Microsoft Edge WebView2 Runtime」即可。
· 老格式 .doc / .xls / .ppt 和 PDF：只能按文件名找，搜不到正文，也不能在线改。
· PPT 只能看每页文字，改内容点「打开」用 PowerPoint。
· 不联网、不上传，只在本机跑。
· 如果把 D:\课程文件库 挪走或改名，桌面快捷方式要重建一次。

八、常见问题
------------
Q 双击没反应 / 一闪而过？
A 看任务栏有没有窗口；若提示找不到 runtime\node.exe，
  从 C:\Program Files\nodejs 复制一个 node.exe 放进 runtime 文件夹。

Q 窗口白屏？
A 缺 Edge WebView2 运行时，或端口被占用（看有没有杀毒软件拦截）。

Q 搜索某词搜不到，但文件里明明有？
A .doc/.xls/.ppt 和 PDF 不索引正文；超过 50MB 的压缩包跳过。

Q 想整个备份？
A 整个 D:\大华教育库 复制走即可，里面是纯文件加 .lib 状态。

Q 能从别的电脑访问吗？
A 不行，只监听本机 127.0.0.1。

九、新加的好用功能（2026-11 版）
--------------------------------
1) 智能标签（左栏"智能标签"）
   软件自动从文件名和文件夹猜出三个维度：校区 / 学期 / 类型。
   点一下 chip 就是筛选，再点取消。可以叠加（如 校区=斗门容闳 + 类型=考勤）。
   列表"标签"列里的浅灰小标签就是自动标签，深色的是你自己打的标签。

2) 重复文件（工具 ▾ → 重复文件检测）
   按内容哈希找出一模一样的文件，显示能省多少空间。
   每组默认保留第一个，勾上别的、点"把勾选的移到回收站"。

3) 系列分组（工具 ▾ → 系列分组）
   把同一文件夹里名字相近的文件归成一组，标出"月份 9、10、12，缺 11 月"。
   适合检查考勤表/教案/课件有没有漏做哪个月、哪一课。

4) 批量改名（勾选文件 → 批量改名）
   支持：查找替换、统一加前缀/后缀、自动加序号、是否用正则。
   下面实时预览改完的样子，确认了再点"开始改名"。扩展名不动。

5) 导出资料清单（工具 ▾ → 导出资料清单）
   把当前筛选结果导成 Excel：文件名、所在文件夹、类型、大小、修改时间、
   智能标签、标签、备注、相对路径。文件在 D:\课程文件库\导出 里。

6) 打包下载（勾选文件 → 打包下载）
   把勾选的若干个文件打成一个 zip，放在 D:\课程文件库\导出 里。
   适合把一学期的资料一次性发给别人。

7) 收藏和最近打开（左栏下部）
   详情面板点"☆ 收藏"就把文件钉在左栏，随时点开。
   每次"打开"过的文件自动进"最近"，最多记 25 条。

8) 我的视图（左栏下部 → 保存当前筛选）
   现在筛的这套条件（搜索词+类型+标签+校区+大小+日期）存下来起个名字，
   下次一点就回到这个状态。可以存多个，右边 ✕ 删除。

9) PDF / 音频直接在面板里看（听）
   选 PDF 文件，右侧就能翻页看，不用调外部程序；
   wav/mp3 会出播放器。

十、最新改动（2026-11-12 下午）
1) 查看文件夹（左栏"类型"里第二行 🗂 查看文件夹）
   点一下，中间就变成文件夹列表：文件夹名、上层文件夹、文件数、子文件夹数、
   总大小、最近修改时间。可以按文件数/大小/时间排序。
   单击一行，右侧显示这个文件夹的概况，有两个按钮：
     · 进入这个文件夹 —— 直接看里面的文件
     · 在资源管理器中显示 —— 用 Windows 的资源管理器打开
   双击任意一行也能直接进这个文件夹。

2) 类型改成"点一下就只看这一类"
   以前点"表格"是叠加筛选，现在点"表格"就只显示表格（其它自然取消）。
   再点一次同一类＝取消筛选，回到全部。
   要同时看两类（比如文档+表格），按住键盘 Ctrl 再点第二个。
   智能标签（校区/学期/类型）仍然是可叠加的。

3) 表头可以直接点着排序
   点"文件名""大小""修改时间"这样的表头，点一下升序、再点一下降序，
   表头上会出现 ↑ 或 ↓。

4) 标签可以删掉了
   右侧详情里，标签后面有个 ✕，点一下就从该文件上摘掉这个标签；
   或者在批量打标签弹窗里点"移除所选标签"。

5) 导入完成的数字更准了
   现在显示"已复制 N 个，跳过 M 个"，不再把跳过的算进复制数。
十一、目录视图怎么用（2026-11-12 再改）
1) 左边"类型"最上面是"全部文件"，默认选中
   选着它的时候，中间列出来的是"当前目录里的东西"：上排是文件夹，下面是这一层
   的文件（就是你打开文件夹看到的样子）。点开软件默认就是库里最外层这一层。
   点文件夹行 → 右侧看概况；双击 → 进去；上面有"← 返回"和面包屑，可以逐级退回。

2) 只想看某一类文件，就点下面的类型
   文档 / 表格 / 演示 / 图片 / 压缩包 / 代码 / 音视频 / 其他。
   点一个＝只看这一类（库里这一层往下所有这种文件都会列出来）；
   按住 Ctrl 再点别的类型＝同时看几类；再点一下同一个＝取消。
   点"全部文件"＝回到不看类型的目录视图。

3) 搜索框是全局搜索
   一输入关键字就自动切成全库搜文件，不受当前目录限制；清空关键字回到目录视图。

4) 文件夹行和文件行是混在一起的
   文件夹永远排在上面，文件排在下面。勾选框只能勾文件，勾文件夹没用。

十二、左栏怎么用（2026-11-12 又调了一次）
1) 左栏从上到下是：类型、智能标签、标签、大小与时间、我的视图、收藏/最近
   除了前两块，后面的标题前面有个小三角，点标题就能展开/收起。
   每个分组会记住你上次是展开还是收起，下次打开还是那样。
2) 原来最下面那个“文件夹”目录树已经去掉了（和中间列表重复）
   现在找文件夹有四种办法：中间列表里点、双击进去、上面“← 返回”和面包屑退回、
   或者直接在搜索框里搜文件夹名。
3) 大小与时间改成了两列
   最小 MB、最大 MB 并排；下面两个是修改时间的起止日期（点一下会弹日历）。
4) 选某个类型的时候，列表里就只出文件，不再夹着文件夹行
   因为“只看表格”的意思是“全库所有表格”，夹着文件夹反而乱。
   想看目录，点回“全部文件”就行。

十三、在资源管理器里新增的文件会自动出现

资料库文件夹（默认 D:\大华教育库）就是普通的文件夹，你可以直接用资源管理器往里拖东西、新建文件夹。
软件会自动发现变化：

· 新建 / 复制进来的文件：1～3 秒内自动出现在列表里（右下角会提示「资料库有变化，已自动刷新」）；
· 新建的空文件夹：也会出现在列表里（文件数 0）；
· 改名、移动、删除：同样会自动同步；
· 大文件夹（几千个文件）刚拖进去时，索引需要多花几秒，等右下角的提示出现即可。

如果等了十几秒还没出现，点右上角「重建索引」手动扫一次。
十四、一键生成考勤表 / 格式转换

【生成考勤表】顶栏「工具 ▾」→「生成考勤表」
1. 月份写 2026-11 这种格式；课程、校区可留空。
2. 「哪几天上课」点一下选中、再点取消，默认选中周六周日。
3. 学生名单一行一个名字，直接粘进去就行。
4. 点「生成」→ 文件存到资料库根目录，名字是「2026年11月考勤表.xlsx」，列表会自动刷新并选中它。
5. 表里公式是活的：在格子填 ✓ / ○ / 半天，右边「实到」「出勤率」自动算。
   打印是横版一页，自带缩放，直接打印就行。

【格式转换】选中文件（可多选）→「工具 ▾」→「格式转换」
- Word / Excel / PPT → PDF：排版跟原文件一致。
- PDF / Word / Excel / PPT → 图片：一页一张 PNG，放在「导出」文件夹里同名的子文件夹内。
- 结果都放在 D:\课程文件库\导出，成功后可以点「打开导出文件夹」。
- 需要本机装了 Office 或 WPS（转 PDF 靠它）；转出来的图片宽度默认 1600 像素。
- 转换过程中界面不会卡，可以继续用；单个文件超过 4 分钟会报超时。

补充：PDF 也可以反过来转
- 选一个 PDF →「工具 ▾」→「格式转换」，可选：图片 / Word 文档 / 纯文本。
- 转 Word 是「把文字重新排成 Word」，不是把 PDF 原样搬过去；图片、表格线、页眉页脚不会保留，适合要改文字的情况。
- 扫描件（整页是图片、没有文字层）转 Word 会没内容，这种请转成图片。

补充二：现在可以转成的格式（点「工具 ▾」→「格式转换」）
- PDF：→ 图片 / Word 文档 / 纯文本
- 图片（png jpg 等）：→ Word 文档（整页图片放进去）/ PDF / 图片
- Word 文档：→ PDF / 图片 / 纯文本
- Excel 表格：→ PDF / 图片 / CSV 表格
- PPT 演示：→ PDF / 图片 / Word 文档（只搬文字大纲，版式不保留）
- 纯文本 / 代码 / json 等：→ Word 文档 / PDF / Excel 表格（每行一格）/ 图片
- CSV：→ Excel 表格 / Word 文档 / PDF

几点说明：
- .ppt 老格式请先在 Office 里另存为 .pptx。
- 转 Word 是「把文字重新排版成 Word」，图片、表格线、页眉页脚不保留；扫描件 PDF 没有文字层，会提示转成图片。
- 反向生成 PPT（做成 .pptx）暂不支持。

补充三：现在用的是 WPS 自己的转换引擎
- 软件会自动找你电脑上装的 WPS，用它的命令行转换组件（kwpsconvert）来转，也就是 WPS 界面里「PDF 转 Word」同一套引擎。
- 因此 PDF 转 Word 会保留图片、印章、表格和大致版式（不再是只抽文字）。PDF 还能转 Excel、转 PPT。
- 第一次转某种类型时，WPS 可能要先下载一个几十 MB 的插件，会等十几秒；之后再转就快了。
- 如果哪天把 WPS 卸载了，PDF 转 Word 会退回到「只提取文字」的老办法，其它格式照样能转。
- 这类 PDF 相关转换在 WPS 里属于会员功能，软件只是调用你本机已授权的能力。

十五、更多格式：内置 Filee 引擎（260+ 种）
- 选中文件 →「工具 ▾」→「格式转换」，在「或者转成其它格式」下拉里挑目标格式，就是走 Filee 引擎。
- 能转的类别：图片(30)、PDF、文档(10)、表格(9)、演示(8)、文本(14)、数据(7)、电子书(15)、韩文 HWP(2)、视频(17)、音频(22)、压缩包(15)、字体(5)、矢量图(7)、CAD(2)、字幕(7)、3D 模型(6)、地图数据(5)。
- 特点：完全离线，不装 Office、不装 LibreOffice 也能把 Word/Excel/PPT 转 PDF；视频音频转码、电子书互转、压缩包互转、HEIC/RAW 转图 都靠它。
- 引擎放在 D:\课程文件库\tools\filee（约 155MB，开源项目 Filee，MIT 许可）。删掉它不影响其它功能，只是没有这 182 种输出格式。
- PDF 转图片会一次生成多张（xxx_p1.webp、xxx_p2.webp …），都放在「导出」里。

补充四：用你自己的模板生成考勤表（2026-11 新增）

要点：软件不重做表格，只改模板里的「日期格」和「姓名」，所以字体、边框、合并、列宽、
红黄底色、下方统计表全都原样保留 —— 就是你惯用的那张表。

用法：
1. 在列表里点一下你的考勤模板（.xlsx，例如「2026斗门考勤（9月）.xlsx」），只选一个。
2. 顶栏「工具 ▾」→「生成考勤表」。
3. 窗口里会出现「用我的模板：xxx.xlsx」，下面一行写着检测结果
   （几个区块、几个学生位、几个日期格、用的是哪张工作表）。
4. 填月份、名单（一行一个），点「生成」。

模板要求（满足就认得出）：
- 有「1 2 3 …」这样连续递增的日期格子（写成「1 
 四」这种数字+星期也行）；
- 有一列表头写着「姓名」（学生 / 学员 / 人员 也认）；
- 姓名列下面就是学生行，一个学生一行。

会自动做的事：
- 日期按目标月份重算，星期跟着变，周末的红/橙底色按新星期重新落到正确的那天；
- 换月后多余的日期格清空；
- 学生行里原来的打勾、半天、⭕ 会清空（避免张冠李戴）；
- 模板下方的统计表（本月假期、上月结余那些）里的旧名字一起换成新名字；
- 只保留这一张工作表并改名为「2026-11」，导出的 PDF 不会再带一整年的表。

限制：
- 学生位只有 6 个时放不下 7 个人，会提示「多出的 N 人没写进去」；
- 如果模板里认不出结构，会退回普通样式生成，并在窗口里说明。

补充五：给不同模板都能用（2026-11 更新）

现在不需要先在列表里挑文件了：
1. 工具 ▾ → 生成考勤表 → 「模板文件」右边点「选择模板…」。
2. 弹出的窗口里挑任意一个 .xlsx（在库里、在桌面、在 U 盘都行），双击文件名直接用，
   或者单击选中再点「用这个文件」。
3. 下面会显示检测结果：「检测到 2 个区块、9 个学生位、31 个日期格（工作表：1月）」。
4. 填月份和名单 → 生成。文件落到资料库根目录。

不同模板都行，只要满足两条：
- 日期格写着「数字 + 星期几」，比如 1 下面写「日」、16 下面写「一」（写在同一个格里也行，
  分两行下上两个格也行）；
- 有一列表头写「姓名」（学生/学员/人员 也认），下面就是学生行，空行也算位置。

认不出时会直接说「这个表里认不出日期格 + 姓名列」，不会硬填坏你的文件。
这时把日期那一行改成「1/日、2/一…」这种带星期的写法就能认出来。

补充六：路径可以直接粘、右键也能直接转（2026-11 更新）

【直接粘路径】

补充八：三种版式的模板都能认（2026-11 更新）

补充十七：教师考勤表怎么填、怎么算（2026-11 更新，两段日期版）

生成的那张表分两块：上面是按天的打勾网格，下面是统计块。

打勾的写法（只要这两种，别的当没写）
- ✓ 或 √ ：算 1 天
- 半天 或 半 ：算 0.5 天
- ○ 或留空：不算（休息）

生成时能填两个数
- 本月假期：这个月放假几天（比如 9）
- 本月上班天数：这个月应该上几天（比如 21）；留空就按「当月天数 − 本月假期」自动算

统计块八列（都是公式，改了勾会自动重算）
1. 本月假期：生成时填的数
2. 本月上班天数：生成时填的数（应上班）
3. 本月实上班天数：自动 = COUNTIF 统计 ✓/√ 记 1、半天/半 记 0.5
4. 调休天数、5. 请假天数、6. 加班天数：留空，自己填
7. 上月结余：上个月结下来的，自己填（新月份从 0 开始）
8. 本月结余：自动 = 上月结余 + 加班 − 请假 − 调休 + 实上班 − 应上班

底部合计行会把每一列加起来。
实测：5 个 ✓ + 1 个「半天」→ 实上班 5.5；应上 21、请假 5、调休 2 → 本月结余 −15.5。

【学员管理系统】怎么用
1. 右上「＋ 新增学员」：姓名必填，其余能填多少填多少
   - 基本信息：性别、年龄、联系电话、家长、学校、年级、班级
   - 报读与费用：报读课程、报名日期、课程费用、优惠、实收
   - 课时：总课时、已用课时（自动算剩余）
   - 状态：在读 / 停课 / 结业 / 退费
   - 备注
2. 费用自动算：应收 = 课程费用 − 优惠；欠费 = 应收 − 实收；
   缴费状态自动标「已缴清 / 部分缴费 / 未缴费」。
3. 顶部五个数字：学员总数、在读、应收、实收、待收（欠费）。
4. 列表可按状态、课程、缴费情况筛；搜索框能搜姓名/电话/课程/班级/备注。
5. 点任意一行就能改；弹窗左下「删除这名学员」可删（删了找不回）。
6. 「批量粘贴」：一行一个学员，逗号分隔，顺序
   姓名, 性别, 年龄, 电话, 课程, 课程费用, 实收, 班级（后面可留空）
   从 Excel 里复制一片贴进去也能导。
7. 「课程与费用」：把常用课程和标准价存起来，填学员时选课程会自动带出价格。
8. 「导出 Excel(CSV)」：导出全部学员（含应收/实收/欠费/剩余课时），Excel 直接能开。

补充二十七：单价按「课次」算（2026-11 更新）

你们这边的算法是：单价 200 元 = 1 个课次，1 个课次 = 2 课时。
所以一门 3200 元的课 = 200 × 16 课次 = 32 课时。

- 「课程与费用」里每门课填四项：费用 / 单价（元/课次）/ 每课次课时（默认 2）/ 总课时。
  例：3200 元、单价 200、每课次 2 课时、总课时 32 → 自动显示「16 课次」。
- 学员选课时四项一起带出；学员自己也能改每课次课时（有的一课次 3 课时就填 3）。
- 单价列现在显示「¥200/课次」；单价留空时按「费用 ÷ 课次数」自动算。
- 已耗课值 =（已用课时 ÷ 每课次课时）× 单价。
  例：上了 6 课时 = 3 课次 × 200 = ¥600；剩 26 课时 = 13 课次 = ¥2,600。

补充三十：应收按「实际报的课时」算，不再按课程标准价（2026-11 更新）

问题：课程预设是 32 课时 3200 元，但学员只报 12 课时、交 1200 元，
以前系统拿 3200 当应收，就误标成「欠 2000」。

现在：
应收 = 单价（元/课次）× 实际课次，实际课次 = 总课时 ÷ 每课次课时
  例：单价 200、每课次 2 课时、报 12 课时 → 6 课次 × 200 = 1200
      报 30 课时 → 15 课次 × 200 = 3000
欠费 = 应收 − 实收（≤0 就是已缴清）
没填单价时，仍按「课程费用 − 优惠」算。

列表也加了「应收」列，能直接看到该收多少。
